# ci-reports — автоматические отчёты Hermes CI

Ветка создана и обновляется агентом **Hermes** (сервер jezv): по расписанию он
проверяет ветки репозитория и прогоняет тесты так же, как GitHub Actions
(`xvfb-run -a uv run coverage run --source=Src -m pytest Tests/ -v`,
`coverage report --fail-under=80`). Ветку не нужно мержить — это только артефакт.

Для каждой тестируемой ветки — своя папка (`/` в имени ветки заменён на `__`):

- `latest.md` — последний отчёт (результат, покрытие, хвост лога);
- `runs/` — отчёты прошлых прогонов;
- `history.csv` — таблица всех прогонов (дата, коммит, результат, покрытие);
- `logs/` — полный лог pytest для провальных прогонов.

Управляется из Hermes; руками не редактировать.
